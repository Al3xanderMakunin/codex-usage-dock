# Codex Usage Dock

[English version](README-EN.md)

Следите за расходом основного 5-часового и недельного лимитов подписки Codex прямо в панели Dock в PowerToys Command Palette. Кольцевые индикаторы становятся янтарными при 80% и красными при 95%. Нажмите на индикатор, чтобы узнать, когда сбросится лимит и когда были получены последние данные.

## Установка на Windows

Понадобятся PowerToys с включёнными Command Palette и Dock, а также локальная установка Codex, которая записывает данные о лимитах подписки.

- Для установки подписанного релиза с GitHub запустите `install.ps1` из репозитория в PowerShell. Скрипт скачает пакет для вашей архитектуры и при необходимости предложит добавить сертификат релиза в доверенные.
- Для сборки и установки из исходников запустите `./pack.ps1 -SelfSign -Install` в PowerShell 7 на Windows с установленным .NET 10 SDK.

После установки перезагрузите Command Palette или перезапустите PowerToys. Щёлкните правой кнопкой мыши по Dock, выберите **Edit** и добавьте **Codex Usage Dock**. Если индикаторы ожидают данные, отправьте сообщение в Codex. Подробности также доступны через команду **Codex usage** в Command Palette.

## Как это работает

Каждые 30 секунд расширение проверяет локальные файлы `rollout-*.jsonl`. По умолчанию оно ищет их в `%USERPROFILE%\.codex\sessions`. Среди файлов сессий, изменённых за последние восемь дней, расширение ищет самое свежее показание по основному лимиту Codex в событиях `token_count`. Оно определяет окна по их длительности и показывает те, для которых есть данные.

Dock отмечает показания старше часа знаком `~`. После сброса лимита индикатор показывает прочерк до следующего замера. Показания обновляются, когда Codex записывает новые данные в локальный журнал сессии, поэтому активность на других устройствах может отобразиться с задержкой.

Если Codex запущен в WSL или хранит журналы в другой папке, задайте пользовательскую переменную среды Windows `CODEX_USAGE_DOCK_SESSIONS_DIR`. Укажите полный путь к папке `sessions`, например `\wsl.localhost\Ubuntu\home\<пользователь>\.codex\sessions`, затем перезапустите PowerToys.

Если вы ранее задали `CODEX_HOME` в Windows специально для Dock, удалите это переопределение и полностью перезапустите ChatGPT Desktop. Эта переменная меняет домашний каталог самого Codex, включая путь к его базе данных. Настройку `CODEX_HOME` внутри WSL можно сохранить.

## Сборка и упаковка

Для сборки нужны Windows, .NET 10 SDK и PowerShell 7. Инструменты упаковки Windows поставляются через NuGet.

```powershell
./pack.ps1 -Register                         # Зарегистрировать распакованное расширение в режиме разработчика
./pack.ps1 -SelfSign -Install                 # Подписать и установить локально
./pack.ps1 -Platform arm64 -SelfSign -Install # Собрать для ARM64
```

Пакеты сохраняются в `out/<platform>/`. Если вы подписываете релиз своим сертификатом, поле Subject сертификата должно совпадать с издателем в `CodexUsage/Package.appxmanifest`. Для сборки под Microsoft Store передайте `-Store` и укажите идентификатор пакета, издателя и его отображаемое имя из Partner Center.
