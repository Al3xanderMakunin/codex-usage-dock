# Privacy Policy

Codex Usage Dock reads local Codex session logs to extract percentages, reset times and the timestamp of the latest rate-limit event. It holds those values in memory. Other log content is discarded after reading. The extension does not modify Codex settings or session files, access credential files, or send data over the network.

Generated gauge icons are stored in `%USERPROFILE%\.codex-usage-dock\icons`. To remove this cache, uninstall the extension and delete that folder.

The **Open Codex usage** command opens the Codex usage page in your default browser.
